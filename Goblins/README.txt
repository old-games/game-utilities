Goblins 3 (Goblins Quest) util to work with IMD files (import/export).
Authors: FullSpektr and Dimouse
Language: Python3 (tested with Python 3.13)

Example of export:
c:\python313\python gob_imd.py export IMD2\

Example of import:
c:\python313\python gob_imd.py import IMD2\NEF1.IMD audio.rus\NEF\NEF1.wav

gob_imd_16bit.py:
Version to work with the special version of ScummVM with added 16 bit sound suppord in IMD files: https://github.com/Dimouse/scummvm
